# 🏥 Hospital Database Management System

## 📌 Overview
The **Hospital Database Management System** is a structured SQL-based project designed to efficiently manage and organize hospital data. It focuses on storing, retrieving, and maintaining critical healthcare information such as patients, staff, appointments, and medical records.

This project demonstrates core **Database Management System (DBMS)** concepts including schema design, relationships, normalization, and query optimization.

---

## 🎯 Objectives
- Design a relational database for hospital operations  
- Ensure efficient storage and retrieval of medical data  
- Maintain data integrity and consistency  
- Model real-world hospital workflows using SQL  

---

## 🧱 Database Features
- **Patient Management**  
  Stores patient personal details, medical history, and visits  

- **Doctor & Staff Records**  
  Maintains information about doctors, nurses, and other staff  

- **Appointments System**  
  Tracks patient-doctor appointments and scheduling  

- **Medical Records**  
  Keeps diagnosis, treatments, and prescriptions  

- **Billing & Transactions**  
  Manages patient billing and payment details  

---

## 🗂️ Database Structure
The system is built using relational tables such as:
- Patients  
- Doctors  
- Staff  
- Appointments  
- Departments  
- Billing  
- Medical Records  

Relationships are established using:
- Primary Keys  
- Foreign Keys  
- Constraints for data integrity  

---

## 🛠️ Technologies Used
- SQL (MySQL / PostgreSQL / Oracle depending on your setup)  
- DBMS concepts (Normalization, ER Diagrams, Relationships)
